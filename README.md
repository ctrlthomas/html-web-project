# Web Authoring Assignment 1A

An HTML website project for the Web Authoring module (5N1910) at Waterford College of Further Education.

## About the Project

This project demonstrates the use of HTML to create a multi-page website. It covers the history of the Internet and World Wide Web, the evolution of HTML and CSS, and a contact form.

## Pages

- **Home (`index.html`)** — Introduction and navigation.
- **History (`history.html`)** — The history of the Internet and World Wide Web, along with web development tools.
- **Evolution (`evolution.html`)** — The evolution of HTML and CSS, document types, deprecated HTML elements, and XHTML.
- **Contact (`contact.html`)** — A contact form demonstrating HTML form elements.

## Technologies Used

- HTML
- Visual Studio Code

## Viewing the Website

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Use the navigation links to visit the other pages.
